## WHAT HAPPENS AT EACH SCHEDULED TIME

**Example: 00:30 UTC (AMMAR's first message)**

1. Systemd timer fires at 00:30
2. Executes: `send-message@AMMAR.service`
3. Runs: `/usr/bin/python3 /home/nizam/send_message.py AMMAR`
4. Script:
   - Generates unique message ID (MSG-YYYYMMDDHHMMSSMMMM-{8HEX})
   - Creates persona-specific message
   - Sends via Telegram to your account (8001780136)
   - Logs delivery to ~/DELIVERY_LEDGER.jsonl
5. Output:
   - Telegram: Message appears in your chat
   - Ledger: Entry added with timestamp, persona, message ID
   - Journal: Execution logged (view with `journalctl --user-unit send-message@AMMAR`)
