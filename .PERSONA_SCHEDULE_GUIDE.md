## HOW TO DEPLOY THIS SCHEDULE

### Option 1: Systemd Timers (Recommended for VPS)

Create 11 timer files on `nizam@31.97.154.5`:

```bash
mkdir -p ~/.config/systemd/user/
```

**Example: AMMAR-nudge.timer**
```ini
[Unit]
Description=NIZAM AMMAR Daily Nudges (2x/day)
After=network-online.target

[Timer]
OnCalendar=*-*-* 00:30:00
OnCalendar=*-*-* 11:30:00
Persistent=true
Unit=send-message.service

[Install]
WantedBy=timers.target
```

**Create service file: send-message.service**
```ini
[Unit]
Description=Send NIZAM Persona Message

[Service]
Type=oneshot
ExecStart=/home/nizam/.local/bin/hermes plugin exec nizam-governor send-message
Environment="PERSONA=%i"
```

**Enable all timers:**
```bash
systemctl --user enable AMMAR-nudge.timer
systemctl --user enable HIKMAH-nudge.timer
# ... repeat for all 11 personas

systemctl --user start AMMAR-nudge.timer
# ... start all timers
```

### Option 2: Crontab (Alternative)

Add to `crontab -e` on VPS:


### Option 3: Python Scheduler (Development)

```python
from persona_schedule import SCHEDULE_SLOTS, PERSONAS
import datetime
import schedule
import time

def send_messages_for_slot():
    now = datetime.datetime.utcnow()
    current_time = now.strftime("%H:%M")
    
    for time_slot, persona_idx, msg_num in SCHEDULE_SLOTS:
        if time_slot == current_time:
            persona = PERSONAS[persona_idx]
            send_telegram_message(persona, msg_num)

# Schedule every minute
schedule.every().minute.do(send_messages_for_slot)

while True:
    schedule.run_pending()
    time.sleep(60)
```

## WHAT HAPPENS AT EACH SCHEDULED TIME

### 00:30 UTC - AMMAR (Message 1/2)

1. Hermes cron job / systemd timer triggers
2. VPS queries knowledge index for AMMAR
3. Phase 16: Generate message with AMMAR system prompt
   - Persona: AMMAR (Plain/Terse)
   - Intent: "Daily nudge"
   - Context: [topics, activity, recent completions]
   - Result: Terse, factual message
4. Phase 17: Send to Telegram
   - MessageID: MSG-YYYYMMDDHHMMSSMMMM-{8HEX}
   - TelegramID: Your account (8001780136)
   - Status: Delivered

   - Ready for response tracking

### 01:30 UTC - HIKMAH (Message 1/2)

Same flow, but with HIKMAH's deep, warm, reflective tone.

### ... and so on every hour

**Result: 22 distinct messages throughout the day, each from a different persona's perspective.**

## FORMAT ADAPTATION (Phase 18)

### Day 1-7: Standard Format

All messages use standard format (<280 chars):
```
"Your AI work has 3 open items. Pick one and move it forward."
```

### Day 8+: Adaptive Format

WeeklyResponseRateCalculator checks 7-day engagement:

- If **< 80%** engagement: Rotate to next format
  - Standard → Short (< 100 chars)
  - Short → Emoji (with visual markers)
  - Emoji → Direct_Question (frame as question)
  - Direct_Question → Story (narrative/analogy)
  - Story → Standard (cycle restarts)

**Example: AMMAR Format Rotation**

```
Day 1-7 (60% engagement):
  "3 items open. Pick one and move."

Day 8-14 (short format):
  "3 items. Pick 1. Move."

Day 15-21 (emoji format):
  "3 items open 🎯 Pick 1, move 🚀"

Day 22-28 (direct_question format):
  "What's your next move: which of 3 items?"

Day 29-35 (story format):
  "Like a sailor picking wind: pick 1 item, catch the wind, move."
```

Each persona independently rotates formats based on their engagement.

## RESPONSE TRACKING & ADAPTATION

### Engagement Calculation

```python
# WeeklyResponseRateCalculator (Phase 18)
7_day_deliveries = 22 × 7 = 154 messages
7_day_responses = 120 (example)
engagement_rate = 120 / 154 = 78%

if engagement_rate < 80%:
    # Trigger format rotation for all personas
    for persona in PERSONAS:
        rotate_format(persona)
```

## CUSTOMIZATION

### Adjust Send Times

Edit `SCHEDULE_SLOTS` in `persona_schedule.py`:

```python
SCHEDULE_SLOTS = [
    ("09:00", 0, 1),   # AMMAR at 9:00 AM instead of 00:30
    ("14:00", 1, 1),   # HIKMAH at 2:00 PM instead of 01:30
    # ... customize all 22 slots
]
```

### Adjust Message Frequency

Change from 2x/day to 3x/day:

```python
# Would add 11 more slots (one per persona)
# Total: 33 messages/day
# Adjust SCHEDULE_SLOTS accordingly
```

### Disable a Persona

Comment out from the schedule:

```python
PERSONAS = [
    "AMMAR",
    # "HIKMAH",  # <- Disabled, won't send messages
    "TARIQ",
    # ... rest
]
```
