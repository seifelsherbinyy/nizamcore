  <behavior>
    GreenhouseSource(BaseSource):
    - name = "greenhouse"
    - __init__(self, config: dict): board_token=config.get("board_token",""),
        company_name=config.get("company_name",""), enabled=config.get("enabled",False)
    - fetch(constraints) -> SourceResult:
        Returns empty + error if board_token blank.
        GET https://boards-api.greenhouse.io/v1/boards/{board_token}/jobs?content=true
        timeout=30. If 429 → return SourceResult(rate_limited=True, errors=["Rate limited (429)..."]).
        raise_for_status() for other 4xx/5xx.
        Parse data["jobs"] → OpportunityRaw list.
        Salary: salary_usd_low=job.get("salary_min"), salary_usd_high=job.get("salary_max").
        company = job.get("company_name") or self.company_name.
        location = job.get("location",{}).get("name","").
        source_url = job.get("absolute_url","").
        On Timeout: return SourceResult with error "Request timeout: ...".
        On any other Exception: return SourceResult with error "Unexpected error: ...".
        NEVER raise from fetch().

    LeverSource(BaseSource):
    - name = "lever"
    - __init__(self, config: dict): site=config.get("site",""),
        company_name=config.get("company_name","Unknown"), enabled=config.get("enabled",False)
    - fetch(constraints) -> SourceResult:
        Returns empty + error if site blank.
        Pagination loop: skip=0, limit=100, max_pages=100.
        GET https://api.lever.co/v0/postings/{site}?mode=json&skip={skip}&limit={limit}
        Stop when response is empty list or len < limit.
        429 → rate_limited=True, return immediately (no retry).
        For each posting: title=posting["text"], location=posting.get("categories",{}).get("location",""),
          company=self.company_name (NOT from response — Lever doesn't include it),
          source_url=posting.get("url","").
        salary_usd_low/high=None always (Lever API doesn't expose salary).
        On Timeout/Exception per page: stop loop, log error, return what's collected so far + error.
        NEVER raise from fetch().
