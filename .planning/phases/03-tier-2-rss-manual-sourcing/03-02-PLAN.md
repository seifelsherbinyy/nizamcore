Key implementation notes:

1. **Imports**: `from __future__ import annotations`, `import logging`, `import requests`, `import xml.etree.ElementTree as ET`, `from datetime import datetime, timezone`, `from .base import BaseSource, OpportunityRaw, SourceResult`

2. **Date helpers** (module-level functions, not static methods, for easy reuse):
   - `_parse_rfc2822(date_str: str) -> str`: try `datetime.strptime(date_str.strip(), "%a, %d %b %Y %H:%M:%S %Z").replace(tzinfo=timezone.utc).isoformat()` → append "Z". Fallback to `datetime.now(timezone.utc).isoformat() + "Z"` on any exception.
   - `_parse_epoch(ts) -> str`: `datetime.fromtimestamp(int(ts), tz=timezone.utc).isoformat() + "Z"`. Fallback on exception.

3. **RemotiveSource** and **WeWorkRemotelySource** share the same `fetch()` logic (XML parsing). Use a shared private `_parse_rss_feed(content_bytes: bytes, source_name: str) -> tuple[list[OpportunityRaw], list[str]]` helper that both call. The only difference is that Remotive reads `<company>` from each `<item>`; WWR has no `<company>` element.

   Actually simpler: each class implements its own `_parse_item(item: ET.Element) -> OpportunityRaw | None` that handles the source-specific field names. Both use the shared `fetch()` template in a parent `_RSSBase(BaseSource)`:

   ```python
   class _RSSBase(BaseSource):
       """Shared fetch() template for RSS-format feeds."""
       name: str = "rss"
       feed_url: str = ""

       def __init__(self, config: dict) -> None:
           self.feed_url = config.get("feed_url", "")
           self.enabled = bool(config.get("enabled", False))

       def fetch(self, constraints: dict) -> SourceResult:
           opportunities = []
           errors = []
           if not self.feed_url:
               return SourceResult(source_name=self.name, opportunities=[], errors=["feed_url not configured"])
           try:
               resp = requests.get(self.feed_url, timeout=30)
               if resp.status_code == 429:
                   return SourceResult(source_name=self.name, opportunities=[], errors=["Rate limited (429)"], rate_limited=True)
               resp.raise_for_status()
               try:
                   root = ET.fromstring(resp.content)
               except ET.ParseError as exc:
                   return SourceResult(source_name=self.name, opportunities=[], errors=[f"XML parse error: {exc}"])
               items = root.findall(".//item") or root.findall(".//{http://www.w3.org/2005/Atom}entry")
               for item in items:
                   try:
                       opp = self._parse_item(item)
                       if opp:
                           opportunities.append(opp)
                   except Exception as exc:
                       errors.append(f"Item parse error: {exc}")
               return SourceResult(source_name=self.name, opportunities=opportunities, errors=errors)
           except requests.Timeout:
               return SourceResult(source_name=self.name, opportunities=[], errors=[f"Request timeout: {self.feed_url}"])
           except Exception as exc:
               return SourceResult(source_name=self.name, opportunities=[], errors=[f"Unexpected error: {type(exc).__name__}: {exc}"])

       def _parse_item(self, item: ET.Element) -> "OpportunityRaw | None":
           raise NotImplementedError
   ```
