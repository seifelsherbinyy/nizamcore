  <files>HIKMAH__knowledge_index/refresh/__init__.py</files>
  <action>
    Create public API module exposing refresh_persona_index() that implements graceful fallback logic.
    
    Main function:
    ```python
    def refresh_persona_index(persona: str, drive_client: GoogleDriveClient, index_path: Path, audit_logger: RefreshAuditLogger) -> Tuple[bool, dict, str | None]
    ```
    
    Returns: (success: bool, index: dict, degradation_reason: str or None)
    
    Algorithm:
    1. Try to query Drive for YAWMIYAT/sessions folder
       - Call drive_client.find_folder_by_name("YAWMIYAT/sessions")
       - If not found, raise IOError("YAWMIYAT/sessions folder not found")
    2. List all files in folder
       - Call drive_client.list_files_in_folder(conversation_logs, file_type='json')
    3. Download and parse each file
       - For each file, call drive_client.download_file_content(file_id)
       - Parse as JSON
    4. Merge activity into cached index
       - Load current index from index_path (via load_cached_index())
       - For each activity file, call merge_activity_into_index()
    5. On ANY exception:
       - Load cached index from index_path
       - Log degradation to audit ledger: status="failure", error=str(e)
       - Return (False, cached_index, str(e))
    6. On success:
       - Log to audit ledger: status="success", files_read=len(activity_files)
       - Return (True, updated_index, None)
    
    Helper functions in this module:
    - load_cached_index(index_path: Path) → dict: Load JSON from file; raise FileNotFoundError if missing
    - initialize_refresh_logger(ledger_path: Path = None) → RefreshAuditLogger: Create logger with default or custom path
    
    Patterns to follow:
    - Never silently degrade: Always log to audit ledger on failure
    - Don't overwrite index on failure: Return cached copy, not a partial merge
    - Catch all exception types (IOError, FileNotFoundError, json.JSONDecodeError, ValueError from validation)
    - Log specific error reason for operator troubleshooting
