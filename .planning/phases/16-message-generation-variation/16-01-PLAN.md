## Persona Definitions

From `NIZAM__system/personas/*.json`, each persona has:
- `codename`: AMMAR, HIKMAH, TARIQ, MUNAWARA, MAL, BADAN, NAQD, SHURA, TAFRIGH, MARSAD, NIZAM
- `tone`: e.g., "Plain, terse, factual" (AMMAR) vs. "Deep, warm, practical" (HIKMAH)
- `role`: e.g., "Builder and custodian" (AMMAR)
- `mode`: e.g., "Weekly synthesist" (HIKMAH)

System prompts in Phase 16 must enforce these tone definitions.

## Telegram Constraints

- **Length:** 280 characters max for mobile readability
- **No PII:** Only safe context tags (technical, health, financial, strategic, personal)
- **Actionability:** Must contain imperative verb or clear motivation
- **Tone:** Consistent with persona definition

## Privacy: Strict Local

- Message ledger is `HIKMAH__knowledge_index/MESSAGE_LEDGER.jsonl` (strict_local)
- No raw personal data in context tags or message text
- No names, email, or identifiers
- Validation gate: Phase 20 (but architect for privacy from start)
