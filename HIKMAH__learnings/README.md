# HIKMAH — Learnings

Arabic: حكمة — "wisdom / insight."

## Purpose
Crystallized lessons. Distinct from raw `LEARNING_LEDGER.jsonl` entries (machine-readable timestamps) — this folder is where you write the *prose* explanation of a principle once it's earned.

## Subfolders (planned)
- `principles/` — durable principles (e.g., "Recovery-first overrides ambition").
- `mistakes/` — mistakes with reasoning so they don't repeat.
- `patterns/` — recurring patterns across domains.
- `heuristics/` — rules-of-thumb that work.

## Status
Shell only. Skills/templates pending future build. Until then, route to `LEARNING_LEDGER.jsonl` and SHURA sessions.

## Privacy
review_before_commit. Insights tied to strict-local domains (finance, body, family) reclassify automatically.
