# INTAJ — Output Engine

Arabic: إنتاج — "production."

## Purpose
The "doing" layer between MUNAWARA tactical plans and actual work output. Tasks, execution plans, agendas, deliverables.

## Status
**Shell only in this Phase 2 commit.** Skills and templates pending future build (when first tactical plan hits this folder for execution).

## Planned skills
- `/intaj-tasks` — task list from current quarter / week.
- `/intaj-agenda` — meeting / day / project agendas.
- `/intaj-deliverable` — track a deliverable from start to ship.

## Privacy
review_before_commit (task lists may contain client names or sensitive context).
