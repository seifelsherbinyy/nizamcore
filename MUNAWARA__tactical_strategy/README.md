# MUNAWARA — Tactical Strategy

Arabic: منورة — "illuminated." (Alt naming: **TADBIR** تدبير — planning/strategy — if you prefer strictly secular.)

## Purpose
Translate KABIR_SHERBO long-horizon bets to 1 / 3 / 5-yr plans → quarters → months → weeks → current battles. Apply the Dynamic War Strategy protocol weekly.

## Skills
- `/munawara-quarter-plan` — quarter plan with roll-up to 1-year.
- `/munawara-weekly-battle` — weekly Dynamic War Strategy protocol + battle ledger.
- `/munawara-pivot` — major pivot record (snapshots affected plans to MAKHZAN).

## Subfolders
- `1_year/`, `3_year/`, `5_year/` — horizon plans.
- `quarters/{YYYY-Qn}/plan.md` — quarter plans with monthly targets.
- `months/`, `weeks/` — execution cadence.
- `battle_ledger/` — prose mirror of `BATTLE_LEDGER.jsonl`.
- `opportunity_maneuvers/` — unplanned opportunity records.

## SUKOON downshift rule
If `SUKOON__recovery_first/overload_flags.jsonl` shows ≥2 red flags in last 7 days, weekly battle load auto-cuts 50%. Non-negotiable.
