# Privacy-Safe Context Summary Policy

## Rules

1. **Never** expose raw sensitive journal text in reminders or outbound messages.
2. Use **themes and summaries** only (e.g. "journal entry dated 2026-06-10 — theme: anxiety").
3. Every outbound message requires a **privacy_level** label: `public_safe`, `private_ai_ok`, or `strict_local`.
4. Strict-local biometrics (WHOOP/BADAN) may appear as **bands and numbers** only when already in approved pulsation snapshots — never quote journal prose.
5. Mark `missing_data` honestly when sources are unavailable; do not fabricate WHOOP, BADAN, journal, or Witness data.

## HIMAYAH gate

Outbound Telegram requires `NIZAM_KHALDUN_OUTBOUND_APPROVED=1` in addition to connector approval.
