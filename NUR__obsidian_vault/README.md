# NUR — Obsidian Vault

Arabic: نور — "light / illumination."

## Purpose
Deep local thinking layer. Obsidian vault that mirrors curated content from POP canonical. **One-way only**: POP → Obsidian, never reverse.

## What syncs
- Curated strategy summaries.
- Non-sensitive reflections.
- Weekly review headlines.
- Learning principles.

## What NEVER syncs
- Raw dumps, sessions, signals, finance, body, family, raw strategy plans, SOUL.md, ledgers.

## Status
Shell only. To activate:
1. Install Obsidian.
2. Open this folder as a vault.
3. Install plugins (Dataview, Templater recommended).
4. Build `/nur-promote` skill in `NIZAM__system/skills/` for selective promotion.
