# NIZAM Kiro capabilities

Workspace foundation: contracts/programs/KIRO_DEVELOPMENT_ENVIRONMENT.md (KDE Phase 1).
Read docs/kiro/capability-registry.md for workflows and docs/kiro/compatibility.md for limits.

Skills live in .kiro/skills; names and descriptions are intended for progressive discovery.
In a fresh Kiro chat ask for a registry positive example and observe actual skill selection.
If automatic activation is unavailable, explicitly ask Kiro to read that SKILL.md file.
Do not mistake file existence or Aki execution for a successful Kiro activation test.

Run node scripts/kiro/inspect.mjs and node scripts/kiro/validate.mjs for metadata checks.
Read scripts before executing. Detailed references are loaded on demand, not preloaded.
No global configuration, MCP server, Power, IDE upgrade or unsupported agent/hook is
activated here. Existing .agents assets and historical specs remain untouched.
