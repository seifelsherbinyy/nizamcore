# QARAR — Decisions

Arabic: قرار — "decision."

## Purpose
Architecture Decision Records (ADRs). Captures notable decisions so future-Seif can re-evaluate later.

## Skills
- `/qarar-decide <topic>` — open the ADR template, capture: title, status, context, decision, reasoning, alternatives, consequences (including recovery cost), review date, confidence.

## Layout
- `{YYYY-MM-DD}__{slug}.md` — one file per ADR.

## Status
Skills and templates are live; scaffolding is real (not shell-only). Use immediately for any notable decision.

## Privacy
review_before_commit. Decisions touching strict-local content (finance, health, family) reclassify to strict_local automatically.
