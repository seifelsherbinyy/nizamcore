# SHURA — Brainstormer

Arabic: شورى — "consultation."

## Purpose
Collaborative thinking partner. Vault-first research. Simplifies technical terms. Converts thought → plan.

## How to use
- `/shura-brainstorm "<topic>"` — co-think a problem, get options + tradeoffs + recommendation.
- `/shura-connect "<note A>" "<note B>"` — bridge two unrelated POP notes.
- `/shura-emerge` — surface unnamed patterns from the last 30 days.
- `/shura-graduate "<fragment>"` — promote an idea to a full project / learning / decision.

## Vault-first rule
Before any external research, SHURA scans POP for what's already known on the topic and produces a delta report. Gaps fill from external sources only after that.

## Layout
- `sessions/` — one markdown per session (filename: `YYYY-MM-DD__topic-slug.md`). **gitignored**.
