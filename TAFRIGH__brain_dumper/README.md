# TAFRIGH — Brain Dumper

Arabic: تفريغ — "unloading / emptying / discharging."

## Purpose
Remove mental clutter daily / twice daily. Capture first, organize later. **Never judge during capture.**

## How to use
- `/tafrigh-capture` — open a new timestamped raw note and dump everything on your mind.
- `/tafrigh-triage` — sort the latest dump(s) into Now / Next / Later / Delete / Reflect / Escalate.

## Layout
- `raw/` — append-only raw captures, one file per session (filename: `YYYY-MM-DDTHH-MM-SSZ.md`). **gitignored**.
- `triaged/` — per-day triage summaries with the 6 buckets. **gitignored**.

## Privacy
**strict_local.** Nothing here leaves your disk by default.
