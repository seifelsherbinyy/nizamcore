# YAWMIYAT — Journaling

Arabic: يوميات — "diary / journal."

## Purpose
Structured journal — longer-form than TAFRIGH raw dumps. Daily reflections + weekly + monthly reviews. Distinct from brain dumps (which prioritize unfiltered capture) and SHURA sessions (which prioritize thinking with a topic).

## Status
**Shell only in this Phase 2 commit.** Skills and templates pending future build.

## Planned skills
- `/yawmiyat-daily` — structured daily entry (gratitude / wins / friction / open loops).
- `/yawmiyat-weekly` — reflective weekly review distinct from `/pop-recap` (machine-generated).
- `/yawmiyat-monthly` — month closer with themes.
