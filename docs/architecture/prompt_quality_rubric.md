# Prompt quality rubric (NIZAM skills)

Score each skill 1–5 on:

| Dimension | 1 (poor) | 5 (excellent) |
|-----------|----------|---------------|
| Specificity | Generic AI filler | Concrete NIZAM modules and paths |
| Privacy | Leaks strict-local examples | HIMAYAH-safe examples only |
| Actionability | Vague advice | Clear operator steps |
| Recovery | Ignores SUKOON | Tiny-mode / crisis paths |
| Testability | No acceptance criteria | Named tests or fixtures |

**Pass threshold:** average ≥ 3.0 across dimensions for GATE-4.
